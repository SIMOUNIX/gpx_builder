# GPX builder

The app is designed to help me build GPX routes and plan my trips outside. The main focus is getting accurate routes with updated OpenStreetMap data. 

# No guessing

All design belongs to the human. **Never guess a design or implementation decision.** Little unsure means **unsure**, every time you have doubt about, pattern design, variables and or functions naming, UI design, UX flows then always ask the human. Bad guess or wrong call is more expensive than a single question to clarify behavior.

Concretely: first investigate and plan rigorously (asking the user design questions along the way), get the plan approved by the user, and only then implement. Implementation should be result of an approved plan never an interpretation.
